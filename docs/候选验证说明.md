## 公开副本的必要适配

- 保留上游 MIT 源码及提交记录，移除原角色素材；只包含用户授权的 8 条春夏正式动画。
- 启动器使用当前用户 LocalAppData；通知快捷方式指向当前安装目录。无开发者账号绑定、绝对工程路径、内部日志或会话。
- 首次默认关闭 Codex 与音频监听，菜单可独立开启。测试配置与正式配置隔离。
- 缺少再分发许可的字体与鼠标图标不附带；保持气泡布局、颜色及系统字体回退。
- 原 Electron 43.3.0 命中公开安全公告，公开候选升级同系列 43.8.0；宿主开发依赖用 overrides 固定 diff 8.0.3、valibot 1.5.0。原本机正式工程不升级。未将 npm 审计结果宣称为绝对安全保证。
- 原宿主锁文件缺失部分 peer 依赖记录，在公开副本补齐，完整类型构建通过。上游测试的虚构家目录改为明确测试目录。

详细日志保留在维护者本地审查区，不随公开仓库或安装包分发。便携包中仅附不含账号与个人路径的测试摘要。
