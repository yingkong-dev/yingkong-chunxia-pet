# 发布与维护

版本由 package.json、CHANGELOG 和 v 前缀 Git Tag 一致标识。当前 0.6.0-rc.3 为候选，禁止当作已正式发布版本宣传。

本地流程：npm ci --ignore-scripts → npm test → npm run audit:public → npm run build → validate-media.py → node scripts/smoke.cjs → node scripts/package.cjs。只有模拟模块、真实视频解码与隔离 Windows 播放均通过才生成带 SHA256 的便携包。旧 dist 目录与同名 ZIP 拒绝覆盖，由维护者先归档。

main 为开发集成，stable 用于人工确认过的稳定版本。本次先建立本地 main/stable 两个分支，均指向候选基线；初始 stable 只是预留分支，不代表 RC 已正式发布或完成用户验收。后续仅在人工验收后推进 stable。现有正式工程继续独立保留，可直接回滚使用，不受公开候选影响。

首次 GitHub 创建、公开推送必须先获得项目所有者授权。取得授权后，核对 GitHub CLI 登录账号与目标仓库名 yingkong-chunxia-pet，再创建仓库和添加 remote；不要自动导入开发工作区旧历史。

Windows CI 在 push/PR/手动触发时测试并构建，默认只读 contents，短期保存已验证便携包。使用固定提交 SHA 的 Actions，Dependabot 每周更新。PR 不采用 pull_request_target，不获得发布凭证。

维护者确认版本与验收后创建签注 Tag，手动运行“仅创建 Release 草稿”。草稿工作流重新验证相同提交，只接收本次产物；Tag 必须与 package.json、提交一致。草稿不会自动转正式。正式发布、覆盖既有版本、改变权限都必须另行明确授权。

仓库建立后建议人工配置 main/stable 分支保护和必需 CI。当前未修改任何 GitHub 安全设置。没有自动合并、删除分支、强推或 AI 自动审查。

## 费用

[GitHub 官方计费说明](https://docs.github.com/en/billing/concepts/product-billing/github-actions)：公开仓库使用标准托管 runner 的运行时间免费；更大型 runner 始终计费。Artifact/Packages 共享存储有计划配额，超额可能计费。本方案使用标准 windows-latest，Artifact 保留 3 天，不启用额外缓存、付费 runner 或付费 AI。私有仓库受账号免费分钟数和存储额度约束，不能承诺零费用。

GitHub 云端 Codex/Copilot 审查未启用。如未来需要，先审核仓库权限、数据范围、API 计价、预算和人工批准方式。本地维护工具本身不额外调用模型 API。

## 人工验收

MANUAL REQUIRED：系统字体替代后的气泡观感、通知横幅、动作切换、边缘效果、多屏缩放、音频设备切换、真实新用户 Codex 登录和额度核对。构建和模拟测试不替代这些验收。Windows 10 和 GitHub 托管 runner 在实际执行前均标记尚未验证。
