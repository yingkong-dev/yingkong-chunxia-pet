# 莺空社区 · 春夏桌宠

基于 [dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 二次开发的 Windows 透明桌宠。当前公开测试版为 **v0.6.0-rc.4**（Pre-release），不是上游官方版本。

春夏和小白龙以桌面陪伴为主：空闲时播放随机动作，点击时回应，也可按本机Codex的可靠状态显示工作反馈。运行采用Electron透明窗口与本地WebM素材。

保留随机待机、点击回应、Codex 状态联动、账号额度、随机气泡、Windows 通知、系统音频待机、动作管理、镜像、尺寸与脚底固定的通透模式。无需购买 API，不附带任何账号或凭证。

## 功能范围

|功能|当前状态与范围|
|---|---|
|透明显示、WebM Alpha、随机待机、点击回应|已实现；8条正式动作，3条普通随机池，旧动作不回退|
|动作菜单、水平镜像、尺寸、拖拽、通透模式|已实现；通透脚底固定，部分含文字动作不镜像|
|Codex工作状态|部分支持：真实running、completed、interrupted；不猜测工具执行、审批或失败细分|
|Codex登录账号额度|已接入官方只读查询、身份核验、自动刷新与阈值提醒；API Key模式不等于订阅额度|
|随机本地文案、Windows系统通知|已实现；真实完成横幅已获确认，不调用AI生成文案|
|系统输出音频监听|已实现音量活跃度与专属待机调度；不识别音乐类型，默认设备热切换仍待人工复核|
|详细诊断与验收入口|开发辅助；验收入口带模拟/测试标识，不改真实账号或任务状态|
|聊天、语音、自动漫游、原版模型碎碎念|当前独立版未接入或未启用，不作为已实现卖点|

## 安装与运行

[下载 v0.6.0-rc.4 Windows 测试版](https://github.com/yingkong-dev/yingkong-chunxia-pet/releases/tag/v0.6.0-rc.4)。新用户默认关闭通透模式，可在菜单手动开启。

目标为 Windows 10/11 x64；目前仅在 Windows 11 普通用户环境实测，Windows 10、其他机器和不同 DPI 尚未全部实测。下载项目 Release 中的便携压缩包，完整解压到可写目录（支持中文与空格），双击 **启动春夏桌宠.bat**。不要只提取 exe。右键可设置、退出；也可运行 **停止春夏桌宠.bat**。包未签名，尚不提供安装器。

首次使用：进入项目 **Releases** → 下载版本对应的 **Windows x64 ZIP** → 完整解压 → 双击启动BAT → 点击/右键体验 → 按需开启Codex联动。预发布不是已覆盖全部环境的稳定版。

源码 ZIP 不包含 Node/Electron 和构建产物，不能直接双击运行。源码开发需安装 Node.js 24.19.0（含 npm）、Windows .NET Framework C# 编译器，然后在项目目录执行：

```powershell
npm ci --ignore-scripts
npm test
npm run build
```

构建结果在 dist/yingkong-chunxia-pet-win-x64。依赖版本由根目录及官方宿主 package-lock.json 固定；构建会下载官方 Electron 43.8.0。无需全局 Python 运行桌宠。Python 与 FFmpeg 仅用于素材验证，不随日常运行启动。

## 首次配置与隐私

Codex 监听、额度查询和系统音频监听默认关闭，请在菜单按需开启。用户配置位于 `%LOCALAPPDATA%/Yingkong/ChunxiaPet`，升级保留设置；不向项目源码目录写账号数据。Windows 通知会注册当前用户的应用身份和快捷方式，不需要管理员权限。

Codex 功能使用用户本机实际安装并登录的客户端。额度通过官方 app-server 只读查询，账号切换重新核验，不创建模型任务；API Key 模式或身份不一致不冒充订阅额度。可用性取决于 Codex 版本、本地认证与网络。状态监听只展示已有可靠事件，不能区分的状态不会猜测成工具、审批或成功。音频仅分析默认输出音量，不监听麦克风、不存录音、不上传。

没有 Codex 也能正常使用桌宠。不要向 Issue 上传认证文件、完整会话、日志正文或个人路径。诊断先脱敏。

## 动作

8 条透明 VP9 WebM，640×360、24fps。待机01/02/03 为随机池；点击回应、任务开始、工作中、任务完成、音乐待机各有独立用途。旧动作不随公开候选分发，运行时不回退旧素材。自定义动作通过“09-桌宠集成/动作配置/动作清单.json”及 assets-manifest.json 管理，正式资源校验失败时明确停止。

## 常见问题

- **启动后没有窗口**：先完整解压 ZIP，在可写目录启动；检查用户数据目录的宿主日志。素材损坏或设置无效会明确报错，请保留原文件并按错误提示修正，不要删除凭证或关闭安全软件。
- **没有 Codex 或暂时不想联动**：保持 Codex 监听和额度查询关闭，基础待机、点击、拖拽、镜像与通透模式可独立使用。
- **任务开始动画没有出现**：先在右键菜单开启监听，再正常提交任务。监听途中启动只恢复可验证的当前状态，不补造任务开始事件；自动切换会等待当前动画播完。
- **额度显示不可用**：确认本机 Codex 是 ChatGPT 登录模式、已登录且网络正常；API Key 模式不等于订阅额度。不要提供或上传凭证，查看菜单中的简要诊断。
- **没有系统通知**：先开启桌宠对应通知开关，再检查 Windows 通知设置和勿扰状态；菜单提供带“【测试】”前缀的测试入口，测试通知不代表真实任务事件已验证。
- **诊断与验收菜单是否影响真实状态**：诊断用于本机排错；验收入口只触发模拟 UI，不更改真实账号额度或任务。当前候选仍保留这些入口，建议普通用户日常使用时不触发，公开 Issue 仅提供脱敏摘要。
- **字体与截图不同**：公开包不分发授权未确认的原版字体，使用 Windows 系统字体回退。可读性和多屏缩放仍需人工检查。
